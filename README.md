# GameMasterStudio

**ゲームのマスターデータ編集を、表計算の手軽さで。変更の確認と共有を、Gitで。**

敵のステータス、アイテム一覧、ステージ設定。ゲームを支えるCSVを、見やすい表で編集するデスクトップアプリです。
値の調整から変更のレビュー、コミット、マージまで、ひとつのアプリで進められます。

## できること

- **表計算のように、まとめて編集。** コピー＆ペースト、連番のオートフィル、行の一括複製に対応。検索やフィルターで対象を絞り、Undo / Redoでやり直せます。
- **「どの値を変えたか」がひと目でわかる。** 追加・変更・削除を色分けし、セルごとの変更前後を確認。その場で個別に変更を戻せます。
- **調整の意図をデータのそばに。** テーブル・行・セルにコメントを残せるので、「この敵のHPを上げた理由」も一緒に管理できます。
- **チームの変更を取り込める。** ブランチの作成、コミット、Push、マージをアプリから操作。競合した値は、自分と相手の変更を比較して選べます。

データはローカルのCSV、コメントと設定も同じGitリポジトリに保存します。コミット履歴から過去の変更も確認できます。

## 使ってみる

現在はソースから起動できます。

必要なもの：Node.js 20.19+ / 22.12+、pnpm、Rust stable、Git CLI、お使いのOSの[Tauri開発環境](https://v2.tauri.app/start/prerequisites/)。

このリポジトリをクローンし、そのフォルダで実行します。

```sh
pnpm install
pnpm tauri dev
```

> グリッドにはAG Grid Enterpriseを使用しています。ライセンスキー未設定時は評価モードになり、ウォーターマークが表示されます。ライセンスは付属しません。取得済みのキーは、`.env.example`をコピーした`.env.local`の`VITE_AG_GRID_LICENSE_KEY`に設定してください。

### 最初のテーブルを作る

1. **Project を初期化**から、データを保存するフォルダを選びます。
2. **Branch を作成**で作業用ブランチを作ります。`main`などの保護ブランチは閲覧専用です。名前とメールアドレスを求められたら、**Project Settings**の**Git Identity**で設定します。
3. **Master を作成**でテーブルを定義します。たとえば、敵のデータなら次の設定で始められます。

   | 項目 | 入力例 |
   | --- | --- |
   | ID | `enemy` |
   | CSV path | `masters/enemy.csv` |
   | Columns（1行に1つ） | `enemy_id`、`name`、`hp` |
   | Primary Key（行を識別する列） | `enemy_id` |

4. 行を追加して値を入力し、**新規行を保存**で確定します。その後のセル編集は自動保存されます。
5. **Change Review**で変更を確認し、コミットします。

あとは敵を複製してバリエーションを作ったり、HPをまとめて調整したり。いつものデータ編集を試してみてください。
