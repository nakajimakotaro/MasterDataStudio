# GameMasterStudio

**ゲームのマスターデータ編集を、表計算の手軽さで。
何を変えたかの確認と共有を、Gitで。**

敵のステータス、アイテム一覧、ステージ設定。

GameMasterStudio は、ゲームを支えるCSVを見やすい表で編集し、変更内容を確認しながらGitで管理できるデスクトップアプリです。

表計算ソフトのように値をまとめて編集しながら、

* どの敵のHPを変更したか
* どのアイテムを追加・削除したか
* リリースに向けて、どのデータが変わっているか

を、CSVのテキスト差分ではなく、行やセル単位で確認できます。

Gitのコマンドを覚える必要はありません。
ブランチの作成、変更の確認、コミット、Push、チームの変更とのマージまで、GameMasterStudioから操作できます。

**表計算の編集しやすさと、Gitの変更管理をひとつに。**
Gitに詳しくないプランナーでも、マスターデータの変更を追える形で管理できます。

## できること

* **表計算のように、まとめて編集。**
  コピー＆ペースト、連番のオートフィル、行の一括複製に対応。検索やフィルターで対象を絞り、Undo / Redoでやり直せます。

* **何を変えたかを、データとして確認。**
  追加・変更・削除を色分けし、セルごとの変更前後を確認できます。
  たとえば `hp: 100 → 120` のように、CSVの行番号ではなく、敵やアイテムなどのデータ単位で差分を確認できます。

* **変更をGitの履歴に残す。**
  編集内容をコミットとして残すことで、いつどんな変更を行ったかを追えるようにします。
  前回のリリースからどのマスターデータが変わったかを確認するための履歴としても利用できます。

* **調整の意図を、データのそばに残す。**
  テーブル・行・セルにコメントを付けられます。
  「この敵のHPを上げた理由」「QA後に再確認したい値」といった情報を、対象のデータと一緒にGitで管理できます。

* **Gitに詳しくなくても、チームで変更を共有。**
  ブランチの作成、コミット、Push、更新の取り込みをアプリから操作できます。
  ターミナルでGitコマンドを入力する必要はありません。

* **競合しても、CSVを直接直さない。**
  チームメンバーと同じデータを変更していた場合も、CSVのコンフリクト文字列を直接編集する必要はありません。
  GameMasterStudio が行・セル単位で変更を比較し、自動でまとめられる変更は自動マージ。本当に判断が必要な値だけ、自分と相手の変更を比較して選べます。

データはローカルのCSVとして保存され、コメントやプロジェクト設定も同じGitリポジトリで管理します。

## 基本的な使い方

GameMasterStudioでは、マスターデータの編集からGitへの保存までをひとつの流れで進めます。

```text
作業用のブランチを作る
        ↓
マスターデータを編集
        ↓
変更内容を確認
        ↓
コミット
        ↓
Pushしてチームに共有
        ↓
他のメンバーの変更を取り込む
```

Gitの細かな操作を覚えなくても、この流れをアプリ上から進められます。

## 使ってみる

現在はソースから起動できます。

必要なもの：

* Node.js 20.19+ / 22.12+
* pnpm
* Rust stable
* Git CLI
* お使いのOSの[Tauri開発環境](https://v2.tauri.app/start/prerequisites/)

このリポジトリをクローンし、そのフォルダで実行します。

```sh
pnpm install
pnpm tauri dev
```

> グリッドにはAG Grid Enterpriseを使用しています。ライセンスキー未設定時は評価モードになり、ウォーターマークが表示されます。ライセンスは付属しません。取得済みのキーは、`.env.example`をコピーした`.env.local`の`VITE_AG_GRID_LICENSE_KEY`に設定してください。

### 最初のテーブルを作る

1. **Project を初期化**から、データを保存するフォルダを選びます。

2. **Branch を作成**で作業用ブランチを作ります。
   `main`などの保護ブランチは閲覧専用です。

   名前とメールアドレスを求められた場合は、**Project Settings**の**Git Identity**から設定できます。Gitの設定ファイルを直接編集する必要はありません。

3. **Master を作成**でテーブルを定義します。

   たとえば、敵のデータなら次の設定で始められます。

   | 項目                   | 入力例                    |
   | -------------------- | ---------------------- |
   | ID                   | `enemy`                |
   | CSV path             | `masters/enemy.csv`    |
   | Columns（1行に1つ）       | `enemy_id`、`name`、`hp` |
   | Primary Key（行を識別する列） | `enemy_id`             |

4. 行を追加して値を入力し、**新規行を保存**で確定します。

   その後のセル編集は自動保存されます。

5. **Change Review**を開くと、今回変更した内容を確認できます。

   たとえば、

   ```text
   Enemy / 1001

   hp
   100 → 120
   ```

   のように、どのデータのどの値を変更したかを確認できます。

6. 内容に問題がなければコミットします。

   必要なら、そのままPushしてチームに共有できます。

あとは敵を複製してバリエーションを作ったり、HPをまとめて調整したり。

いつもの表計算に近い感覚で編集しながら、変更はGitに残していけます。

## GameMasterStudioが目指すもの

ゲームのマスターデータは、日々たくさんの値が変更されます。

表計算ソフトは編集には便利ですが、

**「今回のリリースで、結局どの値が変わったのか」**

を確認する用途には向いていません。

一方でGitは変更管理に強力ですが、CSVの差分は読みづらく、Gitそのものの操作にも知識が必要です。

GameMasterStudio は、

**表計算のように編集し、
ゲームデータとして差分を確認し、
Gitで変更を残す。**

この一連の作業を、プランナーでも扱いやすいひとつのアプリにまとめることを目指しています。
